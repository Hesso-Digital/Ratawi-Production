# Ratawi Production

Ceremony dashboard for the AGUP Phase 1 RFSU opening. A standalone Vite and React app in the Al-Haris family, not part of IOC or WBMS.

- Audience display: `/`
- Hidden operator console: `/operator`

The operator PIN is set in `src/config.ts`.

Data is mock for v1, with a feed interface that can later swap in PI Vision.
